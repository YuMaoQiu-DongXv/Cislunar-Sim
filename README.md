# Cislunar-Sim · 地月系轨道 3D 模拟器

[English](./README.en.md)

一个基于 Web 的地月空间（cislunar space）航天器轨道动力学模拟器：在**地球 + 月球**双体引力场（限制性三体问题）中，用**四阶龙格-库塔（RK4）数值积分**实时计算并可视化航天器的位置、速度与轨迹。

## ✨ 功能特性

- **3D 交互场景**：鼠标旋转 / 滚轮缩放 / 右键平移，星空背景与真实比例天体
- **两种初始轨道输入**，均支持「滑轨拖动 + 数值输入」双输入，并实时预览 t=0 的位置与速度方向：
  - 位置 + 速度（坐标、速度大小、方位角 / 仰角）
  - 轨道根数（半长轴 a、偏心率 e、倾角 i、升交点赤经 Ω、近地点幅角 ω、真近点角 ν）
- **实时数据面板**：模拟时间、速度、距地面 / 月面高度、地球 / 月球引力加速度
- **轨迹显示**：实时绘制飞行轨迹，可切换「最近 30 天」（默认）或「始终显示」两种模式
- **速度可视化**：轨迹可按速度着色（红 = 慢 → 蓝 = 快），或叠加垂直于轨道平面的速度竖线（长度 = 速度）
- **模拟速度可调**：1× 至 1 天/秒，可快速推进
- **预设方案**：保存 / 载入任意初始轨道参数（localStorage 持久化，刷新不丢失）
- **相机预设**：全景 / 地球 / 月球，支持航天器跟随

## 🚀 快速开始

无需构建，单文件即可运行：

```bash
# 方法一：直接用浏览器打开 index.html

# 方法二：启动本地静态服务器（推荐）
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

> 程序通过 CDN 加载 [Three.js](https://threejs.org/)，首次运行需要联网。

### 部署到 GitHub Pages

1. 仓库 Settings → Pages → Source 选择 `main` 分支根目录 → Save
2. 等待部署完成后，访问 `https://<你的用户名>.github.io/Cislunar-Sim/`

## 🔬 物理模型

- **引力场**：地球 + 月球双体（限制性圆三体近似：地球固定于原点，月球以 27.32 天周期沿圆轨道运动）
- **数值积分**：四阶龙格-库塔（RK4），对六个状态量 `[x, y, z, vx, vy, vz]` 积分
- **单位**：km / s；显示比例 1 场景单位 = 1000 km（真实比例）
